# CodeAlpha_Chatbot

## Description
A basic rule-based chatbot built in Python as part of the CodeAlpha Python Programming Internship (Month 1, Task 4). The chatbot responds to simple greetings, common questions, and farewells using predefined logic.

## Features
- Responds to greetings like "hello" and "hi"
- Answers simple questions such as "how are you" and "what is your name"
- Provides a help message when the user types "help"
- Ends the conversation gracefully when the user types "bye" or "exit"

## Technologies Used
- Python 3
- Concepts: functions, if-elif statements, while loop, basic input/output

## How to Run
1. Clone this repository
2. Run `python chatbot.py` in your terminal
3. Type messages like "hello", "how are you", or "bye" to interact with the chatbot
